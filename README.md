# 字戰三國（TDWordWar）

> 一字一兵，成詞成將。

文字塔防：抽到的每個**字**都是一座塔，字有自己的本義與屬性；把相鄰的字組成詞（兵種或武將名），
就會融合成更強的單位並獲得對應特色。目前進度為 **M1 可玩核心**。

## 試玩

```bash
npm install
npm run dev
```

打開 http://localhost:5188 （建議用手機尺寸的視窗，或瀏覽器的裝置模擬）。

## 怎麼玩

1. 按 **征兵** 花「糧」抽 5 個字到手牌
2. 把字放到棋盤的空地上，它會自動攻擊射程內的賊。兩種放法都可以：
   - **拖曳**：按住手牌拖到空地
   - **點兩下**：點一下手牌（卡片會亮金框）→ 點一下空地。手機上比拖曳好按
3. 讓字相鄰組成詞 → 合成武將
   - 兵器／兵種 ＋ 「兵」→ 弓兵、刀兵、騎兵…
   - 姓氏 ＋ 名字 → 黃蓋、馬超、**張飛**、關羽、劉備…（順序要對，張在左、飛在右）
   - 三字配方：諸 ＋ 葛 ＋ 亮 → **諸葛亮**
4. **同字同品質可以疊合升階**（兩個一階「火」→ 一個二階「火」，屬性 ×1.55，上限五階）
   - 棋盤上疊、手牌之間互相疊都可以；手牌出現可疊的兩張時會亮藍框
   - **組成武將之後還能繼續疊**：往「張飛」的「張」上再疊一個「張」，張飛立刻變強
   - **搬動是以單字為單位**：把「張遼」的「遼」拖走，補上「飛」就變成「張飛」
   - **十字成雙**：「張」右邊放「遼」、下方放「飛」→ 同時組成張遼與張飛，共用一個「張」
5. 湊齊特定組合觸發**羈絆**與**組合技**（劉備＋關羽＋張飛 → 桃園結義，並解鎖〈三英戰呂布〉）
6. 謀略字有控場效果：火＝灼燒、計＝減速、風＝擊退、雷＝連鎖、毒＝劇毒、陣／令＝光環增益
7. 兵種相剋：**騎 → 弓 → 步 → 騎**（克制方 +25%）。賊將免疫定身與擊退
8. 經濟字（糧、田、屯、商）不攻擊，但每波產糧；屯＋田 → **屯田** 產量翻倍以上
9. 單位可以**隨時自由拖動**；點一下單位可看屬性、技能冷卻、切換索敵、鏟除
10. 抽到不想要的字可用 **熔爐** 分解，或 **重抽** 整手換新
11. 賊走到「營」就扣 1 生命，生命歸零本局結束

## 心願單

點手牌上方那條列 → 挑一個字設為**心願**，抽到它的機率大幅提高（權重 ×5），手牌上會標一顆 ★。
面板會列出本局字池的每個字能組出哪些武將，讓你看得出許願的價值。起始 1 格，兵書可擴充到 3 格。

## 局外養成

每局結束依抵達波次結算**聲望**（失敗也拿得到，通關另有獎勵），到選單的**兵書**買永久升級：
軍帳擴編（手牌 +1）、求賢令（心願格 +1）、屯糧有備（起始糧 +6）、深溝高壘（起始生命 +1）。

## 抽卡不會太發散

字表有 53 個字，但**一局只會用到其中約 25～35 個**（每關不同），而且姓名字是成組進池的，
所以不會抽到湊不成任何武將的孤兒字。另外已經在手上或場上的字，抽到的機率會提高 3 倍。
開局的提示會告訴你「本局可湊：張飛、關羽…」。

## 關卡

6 關循序解鎖：**黃巾之亂**（教學）→ 討伐董卓 → 巨鹿 → **官渡** → **赤壁** → **五丈原**。
後三關是**隨機地形**，每一局的路都不一樣（保證沒有死路）。左上 ☰ 可回選單，選單裡有**圖鑑**。

## 安裝到手機／電腦（PWA）

打包出來就是一個 PWA，手機和電腦都能「安裝」後離線遊玩：

```bash
npm run build     # 打包到 dist/
npm run preview   # 本機以正式版模式預覽（http://localhost:4173）
```

把 `dist/` 丟到任何靜態空間（GitHub Pages、Netlify、Cloudflare Pages、自己的 nginx…）即可。
`base` 設成相對路徑，所以放在子目錄也能正常運作。

**⚠ 必須用 HTTPS**（或 `localhost`）才能安裝與離線 —— 這是瀏覽器對 Service Worker 的要求。

安裝方式：

| 平台 | 做法 |
|---|---|
| Android Chrome | 網址列右側的「安裝」圖示，或選單 →「安裝應用程式」 |
| iOS Safari | 分享 → 加入主畫面（iOS 只支援 Safari 安裝） |
| 桌面 Chrome／Edge | 網址列右側的安裝圖示 |

安裝後：全螢幕直式、有自己的圖示、**完全離線可玩**（第一次載入後就把全部資源快取起來）。
進度存在 localStorage，離線也照樣累積聲望與圖鑑。

### 發佈到 GitHub Pages

repo 裡已經放好 `.github/workflows/deploy.yml`，推上去就會自動打包發佈：

```bash
git init && git branch -M main
git add -A && git commit -m "字戰三國：文字塔防"
git remote add origin https://github.com/<你的帳號>/<repo 名稱>.git
git push -u origin main
```

> **同一台機器上有多個 GitHub 帳號時**（例如公司帳號與個人帳號），先確認 git 不會
> 拿錯身分。檢查兩件事：
>
> ```bash
> git config --global --get-regexp "url\..*insteadof"   # 有沒有把 github.com 改寫成夾帶 token 的 URL
> git ls-remote --get-url origin                          # 看 git 實際會連到哪個 URL
> ```
>
> 若 global 設定裡有 `insteadOf` 改寫，任何 `https://github.com/...` 都會被靜默換成
> 那組憑證。這時請改用專用的 SSH key 加上 host alias（例如
> `git@github-personal:帳號/repo.git`），alias 不會被改寫規則命中。
> 同時記得設定這個 repo 專屬的身分，否則 commit 會帶著另一個帳號的 email：
>
> ```bash
> git config --local user.name  "你的名字"
> git config --local user.email "你的個人 email"
> ```

然後到 GitHub 的 **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**
（只需要設定一次）。Actions 跑完後網址是 `https://<帳號>.github.io/<repo 名稱>/`。

- Pages 走 **HTTPS**，所以 PWA 直接可安裝
- 專案站台是子路徑（`/<repo 名稱>/`），本專案的 `base` 是相對路徑，**不需要為此改任何設定**
- 第一次開啟需要連線；之後即可完全離線遊玩
- CI 會先跑 `npm test` 與 typecheck，測試沒過就不會發佈

## 指令

```bash
npm run dev             # 開發伺服器
npm test                # 單元測試（92 個）
npm run sim             # 自動平衡模擬（傻 AI 跑 30 局，印出陣亡波次分佈）
npm run sim 16 guandu   # 指定局數與關卡
npm run build           # 打包到 dist/（純靜態 PWA，可直接丟任何空間）
npm run preview         # 用正式版模式預覽（測 PWA／離線必須用這個）
```

`tools/make-icons.html` 直接用瀏覽器開啟，可重新產生 PWA 圖示 PNG。

## 技術

TypeScript + Vite + Canvas 2D，執行期零相依、**零外部圖片與字型資產**（畫面主體就是漢字），
音效由 Web Audio **即時合成**，所以連音檔也沒有。整包 build 起來 gzip 約 34 KB。
PWA 的 Service Worker 是自己產生的（30 行，見 `vite.config.ts`），沒有引入 workbox。
`src/sim/` 與 `src/data/` 完全不依賴 DOM，因此遊戲邏輯可以在 Node 裡跑批量模擬來調難度。
